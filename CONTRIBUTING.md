# Contribuição

Use Python 3.11 ou superior e instale `requirements-dev.txt`. Execute `pre-commit install`, `make lint` e `make test`.

Para mudanças em estoque, preserve a atomicidade e a trilha de movimentações. Para mudanças no esquema, adicione uma migração numerada e valide a atualização com dados legados. Escreva mensagens de commit conforme Conventional Commits.
